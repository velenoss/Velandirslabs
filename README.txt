VELANDRIS LABS — İLK WEB SÜRÜMÜ

İçerik:
- index.html: sayfa yapısı
- style.css: responsive lacivert / elektrik mavisi tasarım
- app.js: menü ve çalışan tarayıcı araçları
- assets/concept.png: tasarım konsepti referansı

ÇALIŞAN ARAÇLAR
- JSON biçimlendirici/doğrulayıcı
- Base64 kodlama ve çözme (çözmek için metnin başına base64: ekle)
- Metin sayacı/dönüştürücü
- QR kod oluşturucu (harici QR servisi ve internet gerektirir)

ÖNEMLİ
- AI Hub şimdilik tanıtım/placeholder alanıdır; gerçek AI API bağlantısı yapılmadı.
- Bu statik site herhangi bir framework veya build aracı gerektirmez.
- Yerel önizleme: index.html dosyasını tarayıcıda açın.
- Yayınlama: dosyaların tamamını hostingin web kök dizinine yükleyin (ör. public_html).
- AI API anahtarlarını asla tarayıcı JavaScript dosyasına koymayın; gerçek AI için sunucu tarafı proxy gerekir.
